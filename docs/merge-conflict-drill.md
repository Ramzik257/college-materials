# Учебный merge conflict (Issue #9)

По ТЗ **каждый** участник должен один раз разрешить конфликт слияния.

## Раунд 1 — конфликт решает A (Ramzik257)

1. A создаёт ветку `feature/9-conflict-a`, меняет строку в `docs/conflict-playground.md`.  
2. B создаёт ветку `feature/9-conflict-b` от актуального `main`, меняет **ту же** строку по-другому.  
3. Сначала merge PR ветки A в `main`.  
4. B делает PR → появляется conflict → **B** разрешает и мержит.  

## Раунд 2 — конфликт решает B… наоборот: конфликт решает A

1. B снова меняет playground-файл в новой ветке и мержит.  
2. A меняет то же место в своей ветке → при merge **A** разрешает конфликт.

Минимум для зачёта: пройти хотя бы по одному разрешению на человека (два коротких раунда).

## Файл для конфликта

Используйте только `docs/conflict-playground.md` — не ломайте рабочий код сайта.
