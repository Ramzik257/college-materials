# Три предложения по продвижению сайта

1. **Кураторы и чаты групп** — короткое сообщение со ссылкой на каталог в чаты курсов (ВК / Telegram): «учебные материалы по HTML, Git, PHP в одном месте».  
2. **Стенд / QR в колледже** — распечатать QR-код на публичный URL и повесить у аудиторий информатики / на доске объявлений.  
3. **Перекрёстные ссылки с занятий** — преподавателям предложить добавлять ссылку на каталог в методички и задания по практике.
