# Сравнение хостингов и публикация

Сайт на **PHP + MySQL**. Нужен хостинг с поддержкой обоих; HTTPS — желательно (на бесплатном техдомене SpaceWeb недоступен).

## Сравнение вариантов

| Критерий | SpaceWeb (free) | Beget (shared) | Timeweb |
|----------|-----------------|----------------|---------|
| PHP + MySQL | Да | Да | Да |
| Цена | Бесплатный тариф | от ~150–250 ₽/мес | от ~150–300 ₽/мес |
| Панель | Своя, на русском | Своя | Своя / облачная |
| HTTPS | На `.temp.swtest.ru` в панели SSL нет (нужен свой домен) | Let's Encrypt | Обычно Let's Encrypt |
| Для практики | Быстрый старт без оплаты | Удобно с своим доменом | Тоже ок |

## Выбор для проекта

Выбран **SpaceWeb (бесплатный аккаунт)**: PHP 8.3 + MySQL 8, технический поддомен без покупки домена.

## Публичный URL

**http://antonovan4.temp.swtest.ru**

- Каталог, регистрация/вход, гость, админка `/admin/` — проверены на хостинге.
- HTTPS на free-техдомене SpaceWeb недоступен («доменов нет» в разделе SSL). Для сдачи используем HTTP-адрес; свой домен + SSL — опционально и платно.

## Домен

- Сейчас: технический `*.temp.swtest.ru` (логин аккаунта в имени не меняется).
- Свой домен — только после согласования оплаты с руководителем.

## Чеклист выкладки (SpaceWeb)

1. Сайт в панели → PHP **8.2/8.3** (не 7.x).
2. Загрузить файлы в `public_html` (без `includes/config.php` из git).
3. Создать БД MySQL в панели; импорт **`sql/hosting.sql`** (без `CREATE DATABASE`).
4. На сервере создать `includes/config.php`: хост, **порт** (часто `3308`), имя БД, логин, пароль из панели.
5. Проверить каталог, вход, CRUD; при сбое — временно `health-check.php`, потом удалить.
6. HTTPS — если появится свой домен; на техдомене пропускаем.

Локально по-прежнему: `sql/schema.sql` + `seed.sql` (+ `users.sql` / `profile.sql` при необходимости).
