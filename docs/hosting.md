# Сравнение хостингов и публикация

Сайт на **PHP + MySQL**. Нужен хостинг с поддержкой обоих и возможностью HTTPS.

## Сравнение двух вариантов

| Критерий | Beget (shared) | Timeweb Cloud / Timeweb |
|----------|----------------|-------------------------|
| PHP + MySQL | Да | Да |
| Примерная цена старта | от ~150–250 ₽/мес (тарифы меняются) | от ~150–300 ₽/мес или пробный период |
| Панель | Своя, привычная для учебных проектов | Своя / облачная |
| HTTPS | Бесплатный Let's Encrypt в панели | Обычно Let's Encrypt |
| Поддержка | Тикеты, база знаний на русском | Тикеты, база знаний на русском |
| Для практики | Удобно: FTP/SSH, phpMyAdmin, домен | Тоже подходит; облако чуть сложнее новичкам |

Цены уточняйте на сайте хостера перед покупкой. **Платные услуги согласуйте с руководителем.**

## Выбор для проекта

Рекомендация команды: **учебный поддомен у руководителя** (если дадут) или недорогой shared-хостинг с PHP+MySQL (Beget / Timeweb — оба ок).

Если поддомен учебный бесплатный — брать его: экономия и проще сдать ссылку.

## Домен

- Вариант A: учебный поддомен от колледжа / руководителя  
- Вариант B: свободное имя на регистраторе (reg.ru, nic.ru и т.п.) — только после согласования оплаты  

## Чеклист выкладки

1. Загрузить файлы проекта (без `includes/config.php` из git — создать на сервере).  
2. Создать БД MySQL, импортировать `sql/schema.sql` и `sql/seed.sql`.  
3. Прописать доступы в `includes/config.php` на сервере.  
4. Включить HTTPS (Let's Encrypt).  
5. Проверить сайт по публичному URL (каталог, вход, CRUD).
